# T3.0 — mock-mcp live in urumi-upstreams

- `apps/mcp-mini`: shared stateless shell (fresh McpServer + transport per
  request, optional bearer, /healthz). woo-mcp refactored onto it (0.1.2,
  regression re-verified); mock-mcp and later the gateway use it too.
- mock-mcp tools: `convert_currency` (fixed table: 100 USD→8320 INR verified),
  `list_products` (deliberate collision with woo-mcp), `sleep_forever`
  (timeout demo), `break_me` (kill switch). No bearer: exercises the
  optional-credential path.
- Image layout gotcha: `file:../mcp-mini` makes `/mcp-mini` a separate package
  dir, so the runtime stage needs its own `npm install` there — Node resolves
  upward from `/mcp-mini/dist`, never from `/srv/node_modules`. Fixed in both
  Dockerfiles after mock-mcp CrashLooped with ERR_MODULE_NOT_FOUND.
- Non-obvious: the final-stage `USER 1000` + `runAsNonRoot` + dropped caps
  already satisfy the per-workload checklist for our Node images, unlike the
  stock wordpress/mariadb images which need root.
